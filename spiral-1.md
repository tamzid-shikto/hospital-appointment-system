# Spiral 1 – Hospital Appointment System

## Objective

The objective of Spiral 1 is to develop the homepage of the Hospital Appointment System as the first iteration of the project.

## Files Added

- `index.html` – Contains the structure and content of the homepage.
- `style.css` – Contains the styling and layout of the homepage.

## Homepage Features

- Navigation bar
- Hospital branding
- Hero section
- Appointment call-to-action
- Why MedCore section
- Medical specialties section
- Call-to-action section
- Footer
- Responsive and user-friendly design

## Spiral 1 Outcome

The first iteration establishes the basic user interface and visual structure of the Hospital Appointment System. The homepage provides the foundation for adding more system features in later spirals.

## Future Work

Future spirals will add:

- Appointment page
- Doctors page
- Sign-in page
- Appointment management
- Doctor management
- Backend and database integration
